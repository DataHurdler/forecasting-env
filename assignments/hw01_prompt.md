# Homework 01: Forecasting Use Cases and Methods

## Overview
This assignment is a short research-and-synthesis exercise.  
You will explain real-world forecasting use cases and identify the tools and techniques used in those cases.

## Objective
Answer the question:
What are common business forecasting use cases, and what tools/techniques are used in practice?

## Task Requirements
1. Select at least 3 real-world forecasting use cases from different domains (for example: supply chain, finance, marketing, macroeconomics, energy, healthcare).
2. For each use case, describe:
   - the forecast target,
   - forecast horizon,
   - the business decision supported,
   - tools used (software/platforms),
   - techniques used (statistical/ML methods).
3. Compare the three cases and explain why different tools/techniques are suitable in different contexts.
4. Provide at least 3 citations (one per use case minimum).

## REPORT.md Format
Use this structure:
1. Brief introduction (what forecasting is and why it matters).
2. Use case table (one row per case).
3. Case details (short subsection per case).
4. Cross-case comparison (tools/techniques tradeoffs).
5. Conclusion (recommended approach patterns for business settings).
6. References.
